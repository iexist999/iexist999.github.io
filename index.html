pocketSandBlocks

Welcome!

pocketSandBlocks is a casual sand game featuring a satisfying falling-sand style cell simulation. As block shapes are falling from the top, your goal is to position them strategically, in such a way, so the sand they eventually crumble into, forms a clear connection between both walls.

With the 12 currently available game modes, you have plenty of fun mechanics to explore! Some of them were created specifically for challenge and difficulty seeking players. Others introduce completely new and unique mechanics, deviating far from the original experience :P

Here are a few examples of the fun gamemodes we've added!

  • classicSand! the classic experience. tiles crumble into sand upon landing.
    casual singleplayer 6 difficulty modes

    GENERAL DESCRIPTION

    tiles fall one at a time and crumble into sand the moment they land. the sand piles up and disperses naturally. its behavior is dictated by the selected difficulty level.
    at lower difficulties, the sand spreads uniformly, forming symmetric pyramid-like structures. at higher ones, sand is replaced by other, less granular materials such as damp dirt or clay.

    as the game progresses, the tiles fall faster and faster, so you have less time to strategize your next move.

    your goal, is to make a connection between both of the horiztonal map borders using same-color sand. if you successfully do so, every sand pixel, that made the connection will be removed. you need to prevent sand from reaching the top of the map, in which case, if there is no more space for new tiles to spawn, the game is over.

    DIFFICULTY LIST:

    DIF1 - Relax: this gamemode is meant for a more relaxed and less demanding gameplay.

    KEY CHANGES

    • granularity set to 100% - sand forms perfectly symmetric piles
    • significantly slowed game speed - tiles fall much slower, and dont speed up
    • additional delay before spawning new tiles
    • 4 classic sand colors
    • 7 classic tile shapes
    • unfiltered random tile selection mode [?]
    • unfiltered random color selection mode [?]

     

    DIF2 - Very Easy: slightly easier than easy :P

    KEY CHANGES

    • granularity locked to 70% - we're not using pure sand no more
    • slow game speed, but it speeds up over time. not by much, but it does
    • 4 classic sand colors
    • 7 classic tile shapes
    • unfiltered random tile selection mode [?]
    • unfiltered random color selection mode [?]

     

    DIF3 - Easy

    KEY CHANGES

    • granularity locked to 50%
    • slightly faster than DIF2, and it also speeds up faster
    • 4 classic sand colors
    • 7 classic tile shapes
    • unfiltered random tile selection mode [?]
    • unfiltered random color selection mode [?]

     

    DIF4 - Medium: the standard experience.

    KEY CHANGES

    • granularity locked to 30%
    • standard game speed. standard speed up
    • 4 classic sand colors
    • 7 classic tile shapes
    • unfiltered random tile selection mode [?]
    • unfiltered random color selection mode [?]

     

    DIF5 - Hard: slightly more difficult.

    KEY CHANGES

    • granularity locked to 30%
    • gamespeed is higher and it speeds up significantly
    • 4 classic sand colors
    • 7 classic tile shapes
    • unfiltered random tile selection mode [?]
    • [OPTIONAL] filtered random color selection - up to 3 same-color tiles in a row

     

    DIF6 - Very Hard: significantly more difficult. you'd need to lock in for this one.

    KEY CHANGES

    • granularity locked to 20%
    • extreme gamespeed and speedup factor
    • random X spawn position for new tiles
    • 4 classic sand colors
    • 7 classic tile shapes + 4 extra large tile shapes
    • unfiltered random tile selection mode [?]
    • [OPTIONAL] filtered random color selection - up to 3 same-color tiles in a row

     

    DIF7 - Insanely Hard: this is the point the game becomes close to barely playable

    KEY CHANGES

    • granularity locked to 10%
    • absurd game speed
    • random X spawn position for new tiles
    • 4 classic sand colors
    • 7 classic tile shapes + 4 extra large tile shapes
    • unfiltered random tile selection mode [?]
    • [OPTIONAL] filtered random color selection - up to 3 same-color tiles in a row
  • classicSandPlus! a classic gamemode featuring extra modifications like lava blocks or bombs.
    singleplayer 3 difficulty modes lava blocks bombs
    everything from classicSand, plus extra pieces mixed into the falling tiles. lava blocks and bombs shake up the terrain, so you will have to plan around them (or put them to good use).
  • elementSoup! a classic gamemode with multiple materials like sand, water, stone, honey and more!
    singleplayer multiple materials
    sand is only the beginning. water, stone, honey and other materials each flow and settle in their own way, so it matters what your connection is made of, not just where it sits.
  • CHAOS! CHAOTIC! gamemode featuring fun events that happen randomly thoughout the game!
    singleplayer random events
    random events strike while you play and you never know what is coming next. adapt on the fly, make the best of it and enjoy the mess!
  • brittleBricks! tiles are made out of brittle brick material, which stays solid, but can crumble upon collision
    singleplayer brittle tiles
    tiles stay solid instead of crumbling into sand, but they are brittle. a hard enough collision breaks them apart, so how you drop and stack them really matters.
